# 小門牌官網

官網入口在 `portfolio/index.html`。原本的 11 個網站示範和資產保留在同一份目錄，根目錄仍是栗樹下指甲工作室示範。

## 預覽

把 ZIP 完整解壓，開啟 `xiaomenpai-official/portfolio/index.html`。官網本身不需安裝或建置，LINE 和 IG 為外部連結。

## 部署

此版本來自公開儲存庫 `waynejman/xiaomenpai-demo` 的 `1f7faf1`。將改動合併到 GitHub Pages 使用的來源分支即可更新官網。保留現有目錄層級，上線地址仍為 `https://waynejman.github.io/xiaomenpai-demo/portfolio/`。部署後可從該網址確認版面、示範、LINE 詢價入口。

改動在 `portfolio/index.html`、`portfolio/assets/`、`hair/index.html`、`pet/index.html`、`booking/index.html` 和本文件。

## 內容核對

- 網站列原作品集的通常價格與範圍。早鳥名額即時狀態未知，本版以定價呈現。
- 訂單整理的訂金金額於確認範圍時約定。訂單表內的商品、日期、筆數及金額皆為虛構示範。
- 四張預覽圖由本專案的髮廊、寵物美容、表單與商品型錄畫面擷取。
